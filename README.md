# 电池大作战

手机浏览器小游戏：起跳、翻转、接住电池。每局 120 秒，六波难度递增，70 颗电池，支持教学、夸张炸飞动画和合成音效。

[立即试玩](https://wentaopeng714-cmd.github.io/battery-brawl/)

手机点击三个动作按钮；电脑使用 F / J / K。

## 本地运行

```sh
npm run dev
```

打开 http://localhost:4173 。执行 `npm test` 运行玩法测试。
